# Tabuada em Jogo

Jogo web (HTML/CSS/JS puro, um arquivo só) para crianças praticarem e decorarem
a tabuada de multiplicação, em duas etapas progressivas:

- **Nível 1 — Lembrar**: `A × B = ?`, uma tabuada de cada vez (2, 3, 4 ... 10) e
  só no fim uma etapa misturada.
- **Nível 2 — Memória**: aparecem dois dos três números da tabuada e a criança
  descobre o terceiro (ex.: `? × 5 = 10`), seguindo a mesma trilha por tabuada
  até misturar tudo.

Cada etapa exige pelo menos 8/10 acertos para desbloquear a próxima.

## Rodar localmente

Não precisa de build nem de servidor: basta abrir `index.html` no navegador.

## Estrutura

Um único arquivo (`index.html`) com HTML, CSS e JavaScript inline — sem
dependências externas além das fontes do Google Fonts.
